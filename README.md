# 💡 Azure Synapse Lab – Querying External Data Sources
In this exercise, you'll use Azure Stream Analytics to process a stream of sales order data, such as might be generated from an online retail application. The order data will be sent to Azure Event Hubs, from where your Azure Stream Analytics jobs will read the data and ingest it into Azure Synapse Analytics.

In this lab, you'll implement a real-time data pipeline using Azure Event Hubs, Azure Stream Analytics, and Azure Synapse Analytics. This architecture simulates ingesting streaming sales order data from an online retail application into Synapse Analytics for real-time analytics and reporting.

## 🎯 Objective  
The goal of this lab is to learn how to **query external data sources (Azure Data Lake)** directly within Azure Synapse Analytics without importing the data.

## 🧠 What I Learned  
- Navigating in Azure Synapse Studio  
- Connecting Azure Data Lake to Synapse Studio  
- Accessing external data in different formats (CSV, Parquet)  
- Querying data without creating traditional tables  
- Leveraging external data sources for quick analysis  

## 🔧 Tools & Services Used  
- Azure Synapse Analytics  
- Azure Data Lake Storage Gen2  

## 🗂️ Steps Followed  

1. Logged into Azure Synapse Studio  
2. Verified and added Azure Data Lake connection  
3. Navigated to the external data folder `sales_data` in the Data tab  
4. Located file paths for CSV and Parquet files  
5. Queried the files directly and explored the data  

## ✅ Outcome  
This lab demonstrated that it is possible to perform **on-demand analytics** on large datasets **without importing them**, using external tables and direct queries. This method enhances **efficiency and speed**, especially in big data scenarios.
